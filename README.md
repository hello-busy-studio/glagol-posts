# Глагол · посты

Система для сборки каруселей бюро Глагол: из текста сотрудника получаются готовые картинки для Instagram и Telegram.

**Как выглядят посты и по каким правилам они собираются, описано в [DESIGN.md](DESIGN.md). Это главный документ.**
Рубрики, тон и правила редактуры: [ТЕКСТЫ.md](ТЕКСТЫ.md) (черновик).
Инструкция для Claude (порядок работы с сотрудником): [CLAUDE.md](CLAUDE.md).

## Как заказать пост (инструкция для сотрудника)

Посты собирает Claude по дизайн-системе Глагола. Вам не нужно ничего устанавливать в проект или знать, как он устроен.

### 1. Начните
Откройте Claude Code и отправьте ссылку на этот репозиторий на GitHub. Claude скачает систему, прочитает правила и напишет, что от вас нужно.

### 2. Пришлите контент — лучше одним сообщением
- **Текстовое ТЗ**: текст поста целиком, о чем он, рубрика (советы, кейс, анонс, вишня и т. д.). Claude не переписывает смысл, только делит текст на слайды.
- **Цветовая тема** — одна на всю карусель. Варианты: зелено-салатовая, зелено-светло-зеленая, оранжево-белая, серая-оранжевая, бело-серо-зеленая, черно-салатовая; дополнительные: персиковая, салатовая, лаймовая, темная-в-рамке. Не знаете, какую выбрать, — Claude предложит 2–3.
- **Формат**: вертикальный (Instagram и Telegram, 2160×2700), горизонтальный (Telegram, 1920×960 или другой размер) или оба. Тип файла — PNG или JPG.
- **Фото для каждого слайда, где оно нужно**, и подпишите, к какому слайду какое. На первом слайде графика обязательна: фото, картинка, 3D-форма, эмодзи или фото из архива (назовите какое).
- **Люди на слайдах**: имя, должность и фото каждого спикера или тренера.
- **Для анонса**: дата, время, формат (онлайн/офлайн), цены, ссылка или QR для записи.
- **Маркировка рекламы**, если пост рекламный: «Реклама. ИП … ИНН … erid: …».

Если чего-то не хватает или что-то не влезет, Claude сразу скажет и спросит.

### 3. Проверьте и пришлите правки
Claude пришлет контактный лист — все слайды на одной картинке. Посмотрите и пришлите **все правки одним сообщением, по слайдам**:

> слайд 2 — заменить фото на …
> слайд 4 — сократить второй пункт
> слайд 7 — акцент на слово «зачем»

Claude внесет правки и пришлет лист еще раз. Правок может быть несколько кругов.

### 4. Заберите файлы
Claude скажет, в какой папке лежат картинки (`посты/<дата-название>/вертикальные/` и `горизонтальные/`).
Если нужно, Claude перенесет слайды в Фигму настоящими слоями. Для этого пришлите ссылку на ваш файл в Фигме. **Перенос в Фигму расходует много токенов**, поэтому заказывайте его, только когда слайды точно нужны в Фигме.

## Структура

```

ТЕКСТЫ.md                  рубрики, голос, структура подписи, редактура
CLAUDE.md                  инструкция для Claude: как делать пост шаг за шагом
движок/
  собрать.mjs              сборка поста → PNG/JPG ×2
  макеты.mjs               HTML-макеты слайдов (32 шт.)
  стили.css                токены и стили
  лист.py                  контактный лист карусели для проверки
  в-фигму.mjs              перенос слайдов в Фигму слоями (по ссылке сотрудника, см. CLAUDE.md)
  фигма-разбор.js          разбор отрисованного слайда на слои
  фигма-сборщик.js         код, который строит слои внутри Фигмы
  браузер.mjs              общий доступ к headless Chrome
ассеты/
  шрифты/                  Wix Madefor Display (OFL)
  фотографии-тренеров/     портреты тренеров + тренеры.json (имя, роль, файл)
  фотографии-спикеров/     спикеры и клиенты из кейсов
  крупные-фотографии/      репортажные фото для обложек
  иллюстрации/3d/          3D-формы для кейсов
  иллюстрации/вишня/       вишни, волна, завитки для рубрики «Вишня»
  иконки/                  стрелка, кавычки, заглушка QR
  текстуры/                шум
примеры-шаблонов/
  базовые/ вишня/ кейсы/   эталонные слайды (как должно выглядеть)

  _шаблон-поста/           заготовка: скопировать и заполнить

  _каталог-рубрики/        темная тема 2026 и макеты доп. рубрик
  _каталог-тг-обложки/     одиночные обложки Telegram 1920×960

  _каталог-вишня/          макеты «Вишни»

    текст.md               исходный текст от сотрудника

    вертикальные/01.png…   2160×2700
    горизонтальные/01.png… 1920×960 (размер настраивается)
```

## Сборка вручную

Нужны Node.js 22+ и Google Chrome. npm-пакеты не нужны.

```bash
node движок/собрать.mjs посты/_каталог-бренд
```

Флаги: `--формат в|г|оба`, `--тип png|jpg`, `--слайд 3` (пересобрать один слайд), `--размер-г 1920x1080`, `--размер-в 1080x1350`.

Для контактного листа нужен Python 3 с Pillow (`pip3 install pillow`):

```bash
python3 движок/лист.py посты/_каталог-бренд вертикальные
```

## Что пополнять

- **Тренеры**: положите портрет в `ассеты/фотографии-тренеров/имя-фамилия.jpg` и добавьте запись в `тренеры.json`. Сейчас там 5 фото без подписей (`_без-подписи/`), их нужно переименовать и подписать.
- **QR-коды**: `ассеты/иконки/qr-заглушка.png` — это заглушка, настоящий QR кладите в папку поста.
- **Новые макеты**: функция в `движок/макеты.mjs`, стили в `движок/стили.css`, строка в каталоге `DESIGN.md` §7 и пример в `посты/_каталог-*`.
