# Пост-карусель Глагола

1. Прочитай `README.md`, `DESIGN.md`, `ТЕКСТЫ.md` (целиком, если еще не читал в этой сессии) и `CLAUDE.md`.
2. Веди сотрудника по порядку из `CLAUDE.md` («Порядок работы с сотрудником»): приветствие со списком, что прислать → вопросы и ограничения одним сообщением до сборки → папка поста из `посты/_шаблон-поста/` → `текст.md` → `пост.json` → `node движок/собрать.mjs посты/<папка>` → контактный лист `python3 движок/лист.py` → проверка по DESIGN.md §9 → лист сотруднику и просьба прислать правки одним сообщением по слайдам → правки → где лежат файлы.
3. Готовые примеры каждого макета: `посты/_каталог-бренд/пост.json`, `посты/_каталог-рубрики/пост.json`, `посты/_каталог-тг-обложки/пост.json`, `посты/_каталог-кейс/пост.json`, `посты/_каталог-вишня/пост.json`. Копируй структуру слайдов оттуда.
4. В конце спроси, нужно ли перенести слайды в Фигму, предупреди, что это стоит много токенов, и попроси ссылку на файл Фигмы сотрудника. Без ссылки не переноси. Порядок — раздел «Фигма» в `CLAUDE.md`.
5. Иллюстраций не рисуй — только фото, ассеты, эмодзи, графика бренда (DESIGN.md §6).
6. Сдавай только после чистой сборки без ⚠️ и визуальной проверки.
